# Hospital-appointment-system
A web-based hospital system built using HTML, CSS, Javascript and PHP, that allows patients to book appointments online and enables administrators to manage patient schedules

#Features; -Patient registration
          -Appointment booking
          -Admin Dashbord
          -Database Storage
          
#How to run the project
 1.Dowload the project files
 2.Open the project folder
 3.Run the project using a local server such as XAMPP
 4.Open the browser and go to locallhost/project name
